# Longevity.Omics - Gen-Decoder report page (design preview)

A design preview of one page of the Longevity.Omics desktop app: a Gen-Decoder report with its interpretation panel, in the new UI style.

Open `index.html` in a browser, or use the GitHub Pages link. `?tab=disease|pharmacogenomic|lifestyle|action|note` opens a tab directly.

Other pages of the application are not part of this preview. All names, results and references shown are illustrative sample data.
